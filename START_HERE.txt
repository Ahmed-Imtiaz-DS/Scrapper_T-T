👋 WELCOME!

This project scrapes Data Science, ML, and AI jobs from top tech companies:
  • Spotify Jobs (https://www.spotifyjobs.com/jobs)
  • OpenAI via Ashby (https://jobs.ashbyhq.com/openai)
  • Airbnb via Greenhouse (https://boards.greenhouse.io/airbnb)

⚡ SUPER QUICK START (2 minutes):

  1. Open PowerShell in this folder
  
  2. Install dependencies:
     python -m venv venv
     venv\Scripts\Activate.ps1
     pip install -r requirements.txt
  
  3. Download ChromeDriver:
     • Go to: https://chromedriver.chromium.org/
     • Download version matching your Chrome browser
     • Extract chromedriver.exe to: selenium\ folder
  
  4. Run pipeline:
     python run_project.py all
  
  5. View results:
     • data/raw/job_links.csv (links extracted by Selenium)
     • data/final/jobs.csv (job details from Scrapy)
     • analysis/workforce_analysis.txt (analysis report)

📁 WHAT'S IN THIS PROJECT:

selenium/
  └─ extractor.py      → Scrapes job boards with Selenium (WebDriverWait)
                         Fixes "404 Not Found" by repairing URLs
                         
scrapy_project/
  ├─ spiders/job_market.py  → Extracts job details from links
  ├─ pipelines.py           → Validates, deduplicates, exports data
  ├─ settings.py            → Scrapy configuration
  └─ items.py               → Data structure definitions
  
analysis/
  └─ summary.py        → Analyzes jobs to answer workforce questions
  
data/
  ├─ raw/              → Selenium output (job_links.csv)
  └─ final/            → Scrapy output (jobs.csv)
  
run_project.py         → Main command-line interface

🔧 TROUBLESHOOTING:

Problem: "ChromeDriver not found"
→ Download from https://chromedriver.chromium.org/
   Place in selenium\ folder

Problem: "404 Not Found" errors
→ Already fixed! Uses WebDriverWait + URL repair

Problem: "No jobs extracted"
→ Check logs in selenium/extraction.log
   Run with headless=False to see browser (edit extractor.py, line 95)
